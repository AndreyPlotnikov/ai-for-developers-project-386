# Календарь звонков

Понятия сервиса записи на встречи с владельцем календаря.

## Термины

**Тип встречи** (Meeting Type):
Вид встречи с заданными названием, описанием и длительностью, который гость выбирает при записи.
_Избегать_: тип события, Event Type

**Рабочее расписание**:
Повторяющиеся по дням недели интервалы времени, в которые владелец доступен для новых встреч, в его часовом поясе.

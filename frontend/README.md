# Фронтенд календаря звонков

React, TypeScript, Vite и Mantine. Инструкции по установке и запуску фронтенда и бекенда находятся в [корневом README](../README.md).

`pnpm generate` обновляет OpenAPI из TypeSpec в `backend/` и генерирует клиентский SDK в `src/generated/`. `pnpm build` запускает генерацию и проверку типов перед сборкой. Сгенерированный код не редактируется вручную.

## E2E-тесты

После `mise run install` установите Chromium и запустите тесты из корня проекта.

```bash
mise exec -- pnpm --dir frontend exec playwright install --only-shell chromium
mise exec -- pnpm --dir frontend test:e2e
```

Playwright запускает Hono и Vite на свободных локальных портах. Для каждого прогона создаётся SQLite в памяти. GitHub Actions запускает эти тесты после `mise run check`. Трассы упавших тестов доступны в `frontend/test-results/`.

Для проверки собранного приложения укажите адрес [контейнера](../README.md#запуск-в-docker) с новым пустым томом. Тесты создают типы встреч и записи.

```bash
E2E_BASE_URL=http://127.0.0.1:3000 mise exec -- pnpm --dir frontend test:e2e
```

Проверки доступности выполняются в Chromium через axe-core и проверяют критерии WCAG 2.0 и 2.1 уровней A и AA. Playwright также проверяет названия элементов, выбор даты и слота с клавиатуры, сообщения и переход фокуса при ошибках и подтверждении. Для ручной проверки откройте приложение в актуальном браузере, пройдите создание типа встречи, запись гостя и просмотр списка владельца с клавиатурой и скринридером. Проверьте видимость фокуса, озвучивание выбранной даты, слота и результатов, включая конфликт и неизвестный исход. При масштабе браузера 200% проверьте читаемость текста и отсутствие перекрытий элементов.

### Ручная проверка релиза

В Chrome 157.0.8103.51 на macOS 26.6.2 при масштабе 200% пройдены создание типа встречи с клавиатуры, переход по прямой ссылке, запись гостя и просмотр записи в списке владельца. В дереве доступности у выбранной даты и слота проверено состояние переключателей. При отправке невалидной формы фокус перешёл к первому полю гостя, при успешной записи — к заголовку подтверждения. Playwright отдельно проверяет отсутствие горизонтального переполнения при ширине окна 640 CSS-пикселей.

Ручная проверка озвучивания остаётся открытой. Запуск VoiceOver через доступное управление macOS не подтвердился. Читаемость и отсутствие перекрытий при увеличении требуют визуальной проверки.
